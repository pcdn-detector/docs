## 配置 `[log]`

```toml
[log]
level = "warn"          # debug / info / warn / error
timezone = ""           # 空 = 自动读取系统时区
hide_address = false    # 隐私模式
```

### 日志等级

| 等级 | 输出内容 |
| --- | --- |
| `error` | 仅错误 |
| `warn`（**默认**） | 警告与错误：配置项被忽略、封禁 / 解封失败、端口被丢弃等 |
| `info` | 额外输出启动参数、检测告警（疑似 / 持续 / 结束）、封禁与解封、UPnP 拦截、抓包缓冲等业务事件 |
| `debug` | 额外输出调试信息 |

默认 `warn` 意味着**普通告警不会出现**。排查「为什么没封禁」「为什么看不到检测结果」时，第一件事
就是把 `level` 改成 `info`——它支持热重载即时生效，不必重启进程。

### 时区

按顺序尝试：`-z` / `--timezone` 参数 → `TZ` 环境变量 → OpenWrt 的 `/etc/TZ` → 系统默认
（可能是 UTC）。支持 IANA 名称（`Asia/Shanghai`）或 POSIX 串（`CST-8`）。

C 版使用 IANA 名称时要求目标系统存在 `/usr/share/zoneinfo`（Alpine 需装 `tzdata`）；
用 POSIX 偏移写法（`8:00`、`CST-8`）则无此依赖。

启动日志会说明时区来源：

```text
日志时区：CST（来源：/etc/TZ，当前偏移 +08:00）
```

### 隐私模式

开启后日志中的**设备自身**身份信息被掩码：

| 类型 | 原值 → 掩码 |
| --- | --- |
| MAC | `60:21:01:1b:0a:23` → `60:21:...:23` |
| IPv6 | `2408:8240:9411:37b0:4e9:adaa:3a1a:b2a3` → `2408:8240:...:b2a3` |
| 公网 IPv4 | `112.245.115.51` → `112.*.*.51` |
| 内网 IPv4 | `192.168.1.100` 保持原样（非公网地址） |

规则：MAC 与 IPv6 保留**前两段与最后一段**；公网 IPv4 保留**首段与末段**。远端对端 IP
（告警中的「相关IP」）**不受影响**，始终完整展示，便于定位。

该选项**只影响日志展示**：黑白名单、防火墙封禁仍使用真实 MAC / IP；HTTP API 也返回原始值。
命令行等价项 `-H` / `--hide-address`。

封禁 / 解封同样按 `info` 输出（`已封禁`、`已解封`、`已执行全 UDP 端口封禁`）。

## 在 OpenWrt 上查看

日志写 stdout，由 procd 收集进系统日志，**syslog tag 为二进制文件名**：

```text
Sat Oct 24 12:00:42 2026 daemon.info pcdn-detect[1234]: ... 疑似产生PCDN行为 ...
```

```bash
logread -e pcdn-detect            # 按 tag 过滤
logread -f -e pcdn-detect         # 实时跟踪
```

LuCI 面板的「日志」页同样按 tag 精确筛选，不会把正文里提到 `pcdn-detect` 的其它进程日志混进来。
可查看的历史长度取决于系统日志缓冲区，需要长期保存请配置 `logread` 落盘或远程 syslog。
