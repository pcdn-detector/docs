## 这是什么

pcdn-detector 是面向家庭网络的 PCDN 检测与阻断工具，用于在 **OpenWrt / Linux 路由器**上识别局域网内的
P2P CDN（PCDN）行为，并可自动阻断。它不是流量整形工具，也不看具体应用协议，只用一条统计特征判断：

> 某台设备在**指定时长**内，通过**同一个本地端口**连接了**超过阈值数量**的**不同远端公网 IP**。

这条特征对 PCDN 非常有效——正常客户端即便并发很高，也很少在单个端口上连出几十个互不相关的
公网 IP；而 PCDN 节点为了就近回源，恰恰就是这么做的。

## 三个仓库

| 仓库 | 角色 | 语言 / 运行时 | 说明 |
| --- | --- | --- | --- |
| [`pcdn-detector`](https://github.com/Womsxd/pcdn-detector) | 检测内核（Go） | Go 1.27.3+，纯 Go、无 CGO | 交叉编译静态二进制；AF_PACKET + TPACKET_V3 |
| [`pcdn-detector-c`](https://github.com/Womsxd/pcdn-detector-c) | 检测内核（C 移植） | C23，pthread | 无 GC、体积更小；AF_PACKET + TPACKET_V2 |
| [`luci-app-pcdn-detector`](https://github.com/Womsxd/luci-app-pcdn-detector) | LuCI 管理面板 | Lua / LuCI | 仅前端，**不含检测二进制** |

三者共同组成一个完整方案：**内核做检测与封禁，面板做配置与观测**。两个内核的功能、配置格式、
命令行参数、HTTP API、状态文件格式与发布产物命名保持一致，可以互相替换。

## 检测原理

1. **加载配置**：读取 TOML 配置，命令行参数覆盖同名项。
2. **抓包**：在指定网卡上用 `AF_PACKET` 抓包，socket 挂内核层经典 BPF 过滤器，默认只放行 UDP，
   ARP / STP / ICMP 等无关报文在进入用户态前就被丢弃。
3. **统计**：解析以太网、IPv4 / IPv6（含扩展头）、TCP / UDP 头部，按
   `设备 MAC + 本地端口 + 协议` 统计滑动窗口内不同远端公网 IP 的数量。
4. **告警**：数量达到阈值输出「疑似产生PCDN行为」；随后进入**持续期**，期间只要该端口仍有流量
   就刷新计时器，出现新对端时额外输出「持续产生PCDN行为」；持续期内无任何流量则输出
   「PCDN行为结束」。
5. **过滤**：若配置了黑白名单，按设备 MAC（可再限定端口）决定「检测谁」或「不检测谁」。
6. **联动封禁**：首次告警即封禁该设备在该端口上的流量，行为结束时解封；可叠加全 UDP 端口封禁。
7. **UPnP 拦截**：可选，拦截设备发往路由器的 SSDP / HTTP 控制请求，阻止其自动打洞。

:::tip[部署位置]
必须跑在**能看到设备真实 MAC 的 LAN 侧网桥接口**（如 `br-lan`）。挂在 WAN 侧只能看到 NAT 后的
地址，挂在纯三层接口上则拿不到 MAC，都会导致判定失效。
:::

## 能力一览

| 能力 | 说明 |
| --- | --- |
| 单端口多对端检测 | 核心判定逻辑，阈值与窗口可调 |
| 三段式告警生命周期 | 疑似 → 持续 → 结束，可重复触发 |
| IPv6 完整支持 | 解析并跳过各类扩展头；按「端口 + 地址族」分别统计 |
| 黑白名单 | 按 MAC 过滤，可限定端口，支持临时停用单条 |
| 防火墙联动 | `hook` / `iptables` / `nftables` 三种后端，自动封禁与兜底解封 |
| 全 UDP 端口封禁 | 多端口被封后升级为设备级全封禁，仅放行常用端口 |
| UPnP 拦截 | 随名单方向决定拦截范围，与封禁共用防火墙后端 |
| HTTP API | 状态读取、设备与端口明细、手动解封、热重载 |
| 热重载 | `SIGHUP` 恒定可用；HTTP 开启后可用 `POST /api/v1/reload` |
| 状态继承 | 兜底重启时通过二进制状态文件继承告警与封禁（PCST v1） |
| 低内存适配 | 抓包缓冲、`snaplen`、对端上限、端口上限、低内存模式 |
| 隐私模式 | 日志中隐藏设备自身 MAC / IPv6 / 公网 IPv4 |
| LuCI 面板 | 状态、TOML 全文编辑、在线校验、日志、二进制下载与回滚 |

## 不做什么

- 不解析应用层协议：判定只看连接行为，不区分 BitTorrent、网盘或 PCDN 厂商。
- 不做限速 / QoS：只有「放行」与「丢弃」。
- 不提供 HTTPS：HTTP API 仅明文，需要加密请在前置反向代理终结 TLS。
- 不保证零误报：阈值需要按实际网络规模调整，见[检测与抓包](/config/detect/)。
